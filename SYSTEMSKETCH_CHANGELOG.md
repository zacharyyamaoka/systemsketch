# SystemSketch changelog

## 0.1.0

- Started from the stock tldraw 5.3.2 whiteboard and default interface.
- Added a bottom-right utility strip for board overview, zoom, and Help-hosted release controls.
- Added a green Help indicator only when newer Preview work is available.
- Made Help quiet when Stable is current, with a fixed Version & updates row and a conditional one-click Preview spotlight.
- Refreshes release availability in the background on startup, every 15 seconds, and when the app regains focus, visibility, or connectivity.
- Added a persistent top-center Preview marker with a direct Return to Stable action, shown only in Preview.
- Added a seven-slot Figma-style toolbar with remembered shape/draw families, repeated-A arrow cycling, and a searchable tldraw shape library.
- Made Open Live Preview launch an independent duplicate of the current board in a new window.
- Kept Stable immutable while Preview hot reloads from the SystemSketch repo.
- Replaced browser-only persistence with a local `.tldr` workspace: smart reopen, recents, autosave, Open/Save As/Rename/reveal/Trash actions, and desktop file association.
- Added atomic, path-confined writes plus a content-digest conflict fence and clean external-change reloads.
- Made Live Preview detect and restart an outdated launcher-owned workspace controller before opening the duplicated board.
- Routed Open and Save As through the native desktop file chooser, with a scrollable in-app workspace browser retained as fallback.
- Kept the native chooser off the busy home-directory root by creating and preferring the dedicated `~/SystemSketch` folder.
- Added a gear-led Settings window with a persistent 80–160% interface scale that enlarges app chrome without changing canvas zoom or `.tldr` content.
- Added a dedicated Dev shelf beside Help for Stable, Latest Preview, version controls, and recent-first isolated presets.
- Added pre-mount `Block Dev` and `Stock tldraw` compositions on the one Preview runtime; each isolated preset owns an independent browser-local board while Latest Preview keeps the current-board duplicate flow.
- Added the Block / Port / Edge tracer bullet to `Block Dev`: stock toolbar integration, right inspector, remembered Simple/Port/Expanded views, real nested frames, stable port identities, and semantic port-to-port cables that follow movement, survive hide/reload, and participate in tldraw history.
- Added view-only Depth Stack navigation for Expanded Blocks: camera-fitted scope boundaries, numeric arbitrary depth, structural Up, direct ancestor/root jumps, and exact root-camera recovery over the real `parentId` chain.
- Ported pyblocks' native semantic context menu: checked Block views, Add Input/Output/Icon/Description/Type with immediate inline editing, checked Offset/Aligned port layout, Expanded depth entry, and Curved/Straight connection routing while retaining stock tldraw commands.
- Kept the context menu on tldraw's public default root and stock content, made batchable Block items survive multi-selection, and reset the stock Radix root on desktop-window blur so returning to SystemSketch cannot strand the next right-clicks on an invisible capture layer.
- Made every text box WYSIWYG through one field contract: each keystroke writes straight into the document, and blur, Enter, Escape, another control, a tab switch, and the panel unmounting on deselect are all the same commit boundary — closing the inspector edits that were silently dropped because Chrome fires no `blur` for a removed element.
- Bounded each typing gesture with a single history mark in both the inspector and the on-canvas editor, so one Ctrl+Z retracts a whole rename instead of one character — and undoing an on-canvas rename no longer deletes the Block.
- Made a Block's text open the way a rectangle's does: one click activates the Block, the next click — fast or slow — opens the field under the pointer, and a further click moves the open editor onto a second field. tldraw's stock click-to-edit is gated on a shape having exactly one text label, which a Block never has, so only a rapid double-click used to work; a miss on the body, footer, or frame interior still opens nothing and Expanded double-click still steps into depth.
- Made multi-selection batch the way it does on a stock tldraw rectangle: `view`, `portLayout`, `showDescription`, and connection `routing` are now real tldraw `StyleProp`s, so the inspector stays open for many Blocks and shows the shared value or **Mixed**, the mini menu names the batch and switches Simple/Port/Expanded in one click, and the right-click menu applies to the whole selection — Blocks inside groups included, non-Block shapes untouched, one history step per gesture. Title, type, notes, and ports stay behind a single selection because a batch write would overwrite each Block's identity.
- Fixed a right-click menu that only opened once per page session. tldraw's stock context-menu root is uncontrolled on Radix's side while tldraw mirrors it into its own registry, and `MenuClickCapture` clears that mirror straight from the dismissing pointerdown — so Radix's `open` stayed `true` and every later `contextmenu` was a no-op. The root is now remounted when the wedge is actually observed (and on window blur), and the right-click that hit it is replayed against the fresh root, so the user's own click is the one that opens. Reproduced first with a plain rectangle in the unmodified `Stock tldraw` profile.
- Made Preview a two-way door. The always-visible Preview marker now carries both exits side by side — **Return to Stable** and **Make Preview Stable** — so promoting the working tree is one reachable button instead of a Publish Preview row buried inside the collapsed Version & updates section. The committing click is armed first: it restates the consequence (`Confirm · replaces Stable`) and only the second click starts the check-and-build, because a control that sits on screen permanently must not be able to launch a multi-minute build by accident. Clicking elsewhere or pressing Escape disarms it, and Escape does not also close the panel it was armed from. While the build runs both exits lock and the marker says what is happening; when it lands, Stable updated replaces the button and Return becomes Open new Stable.
- Stopped the Dev shelf calling out the view you are already in. In Preview, Latest Preview drops its call-out gradient and becomes inert state — **You are here · Current** — with the two channel buttons directly under it and Stable reduced to the quiet row saying what launches by default; from Stable the same row keeps the gradient, because there it really is the offer. The marker also stopped repeating the composition name it can only ever be, since the panel never mounts outside the full product.
- Moved port editing into the Block itself, borrowing a table's own gestures. Hovering the empty end of a lane on a selected Block reveals a **+** on the row the port would occupy — inputs on the left half, outputs on the right — and one click creates the port with its name editor already open. A full Block now grows to fit the new row instead of silently squeezing the ones already there, because `layoutBlock` compresses the row pitch to whatever space is left; `blockPortViewHeightForSlots` is the exact inverse of that clamp and lives beside it. **Press and hold** a port and its row lifts onto a card with a grip and a drop rule, riding tldraw's own `long_press` into a new `select.dragging_block_port` state beside the existing cable gesture — so a press that moves first is still a cable, nothing is written until the drop (cables stay put while a port is in flight), and the whole reorder is one undo step that never touches a port id. **Right-clicking a port** re-aims the existing menu rather than opening a second one: Add port above / below, Move up / down, Delete port are prepended above Block view, Add, Ports and every stock command. The subject is resolved from tldraw's `right_click` and the cable magnet radius, not the DOM target, because the browser only raises `contextmenu` on the release, by which time the painted dot is no longer topmost and the click reports against the canvas.
- Diagnosed the two boundary-port edge bugs and planned the edge rebuild — no `src/` change. A port's *side* is its *terminal* in this model, and at an Expanded block's boundary that equation is not merely too strict, it is **inverted**: `run.in_1 → decode.in_1` and `decode.out_1 → run.out_1` — the only two wirings a hierarchy needs — are both refused, while `decode.out_1 → run.in_1` and `run.out_1 → decode.in_1` both bind. All four cells are driven in the real product build by `tests/boundary_port_edge_diagnosis.mjs` (`npm run test:edges`), which asserts the *desired* column so a run that starts passing is the signal a fix landed. The second bug is unrelated: a tap on a port arms `select.connecting_block_port`, a state neither tldraw starter kit has, and `editor.setCurrentTool` is a plain `root.transition` that runs `onExit` without dispatching cancel / complete / interrupt — so pressing **A**, or clicking another toolbar tool, strands a half-bound cable for the rest of the session (Escape bails correctly; a reload prunes it). Both kits answer this by not having the state: a tap, and a drag that lands on nothing, open the on-canvas picker instead — the same edit that removes the bug adds the drag-to-nowhere-then-place-a-block feature. `docs/block-edge-rebuild-2026-09-01.html` carries the evidence, the boundary diagram, the kit / pyblocks / SystemSketch capability inventory, the port-target-zone numbers, and a six-phase plan.
- Rebuilt the data edges from the tldraw starter kit's module boundary plus the mature pyblocks donor, applying all six planned phases. **Boundary inner faces**: every port derives a `…__inner` twin at the same anchor with the flipped terminal, live only in Expanded but present in every view so a welded cable survives a view switch — and, because both faces share a coordinate, a *scope* rule decides which one a drop may meet (a cable whose other end is inside this Block meets the inner face; anything else meets the outer one). That flips all four boundary wirings at once: `run.in_1 → decode.in_1` and `decode.out_1 → run.out_1` now bind, `decode.out_1 → run.in_1` and `run.out_1 → decode.in_1` are now refused. The press also had two authorities choosing a face — the capture-phase DOM listener re-derived "nearest port" and overruled the painted dot because `queueMicrotask` ran it last; there is one authority now. **The armed tap-to-place state is deleted rather than patched**, so no state outlives its gesture and there is nothing left to enumerate exits for; the click it was occupying became the on-canvas Block picker, which a drag into empty space and a tap on a port both open, placing the new Block so its first matching port lands under the cable end and opening its title editor. The offer's lifetime derives from the live tool id, so `A`, the toolbar and any future tool are one rule. **Refusal is now visible**: a drag lights every port it could legally land on and the one under the pointer louder, with a cycle veto that exempts hierarchy edges, and an occupied single-connection input replaced rather than doubled (deferred to the drag end, so an abandoned drag never destroys the wire it hovered). **The hit profile from 2026-08-27** landed whole — corridor ±9u, port snap 18u, reconnect 10u, every number derived from the port dot's own CSS — including the measurement that tldraw *ignores* a caller's `margin` on the open-geometry branch, so the corridor is padded on the geometry, live, at every zoom. **The edge editor**: the pure elbow package (A*, pins, path, nudge — 1,800 lines, 73 tests, no tldraw or React import), three routings, a control point that activates a straight cable into a curve, per-segment rails on elbow with authored routes running between fixed port dongles, Figma's selected-and-near reveal rule, a `+` at each cable's midpoint that splices a Block in while keeping both original ends wired, cables painted under Blocks per parent, and a connection inspector so a selected edge finally has a home in the dock. Proven in the real product build: `npm run test:edges` 32/32, `npm run test:edge-editor` 20/20, 289 unit and 24 Python tests, and all six pre-existing browser journeys re-run green.
- Took Delete out of the floating selection pill everywhere, matching both reference apps: FigJam and Excalidraw each keep it out, and Delete/Backspace and the right-click menu already delete. This also ends a live inconsistency where selecting one rectangle offered Delete and selecting one Block did not, at the same pill position under the same gesture.
- Pinned canvas-anchored chrome at every interface scale. The scale enlarges chrome with CSS `zoom` on the surface layer, and `zoom` establishes a *new coordinate scale* for everything inside it — so a child placed at `translate(400px, 300px)` inside `zoom: 1.4` renders at (560, 420). That is right for chrome laid out against the window and wrong for chrome positioned from the **camera**, which computes real viewport pixels for a board that deliberately does not scale. Three surfaces were in the second category and inside the zoomed layer: the on-canvas Block picker, the selection contextual menu, and the depth-scope mask. Measured before the fix, the picker landed at (908, 466) at 100% and at (1271, 652) at 140% — exactly ×1.4. A three-line exemption cancels the layer's zoom for those three; the two that are still chrome re-apply the scale as a `transform` about their own top-left anchor, so they grow without moving, while the depth mask does not re-apply it at all because it is tracing the board rather than the interface. The selection menu's placement also now re-runs when the scale changes, since a transform does not fire a `ResizeObserver`. The Block offer additionally clears the selection when it opens, so the selection menu no longer competes with it for the same click. `npm run test:scale` drives the real product at both scales and asserts anchor, growth and the mask's non-growth: 12/12, and 7 of the 12 go red when the exemption is removed.
- Removed the `+` at each cable's midpoint, and with it the splice-a-Block-into-a-cable feature it was the only entry point for. An existing edge now offers exactly its control points.
- Replaced the control-point reveal rule with Figma's: a rectangle that fits the arrow's own outer extents, padded 24px, recomputed as the arrow bends — not a distance to the stroke. The old rule was fine for a curve and simply wrong for an elbow, because a wrapping route encloses a large empty area: measured in the running app, the point inside such a box that is farthest from any stroke sits **151 px** away, and standing there the pointer is unambiguously on the arrow. Padding is twice tldraw's handle radius, so the region reaches exactly as far as a control point you could already grab if one sat on the boundary; a 64px floor keeps a nearly degenerate cable's region landable. Selection is still required alongside proximity, as in Figma. Revealed points also get a 9px halo painted *underneath* them by an additional overlay — tldraw's own handle radius is hard-coded at 4px, and an extra ring gets the same result without forking its renderer. And one rule now covers every piece of chrome: a pointer over anything outside `.tl-canvas` is not a pointer over the board, so reaching for the contextual menu no longer lights up the control points the menu offers an alternative to.
- Moved the add-port `+` onto the Block's edge, in the column the port dots occupy. Its centre now comes straight out of `layoutBlock` for the Block that already has the new port — the same call that supplied its row now supplies its column — so the bead and the dots cannot drift; measured `dx = 0.00` against both edges on an Expanded Block with zero ports. The hover band is 40px centred on that line, the width of the halo a port dot already paints, capped so two bands can never meet on a narrow Block. The bead became a hollow ring because tldraw paints its 2px selection line down the middle of anything on the edge and it was erasing the white plus's vertical stroke.
- Made the Block offer finish *on* the cable, the way the image-pipeline kit does it: the loose terminal lands on the panel's near edge at the height of the first option, with the anchor row measured from the rendered panel rather than guessed. A cable reaching left for a producer puts the panel on the far side so it does not lie over the wire, and flips back when that would land it off-screen.
- Added a development hit-area overlay: `?hitareas=1` on any board, or **⇧H** on the canvas, draws every region that answers a pointer — control-point reveal, port drop snap, reconnect radius, add-port gutter — in red, painted from the same functions the hit tests call. Compiled out of released builds. `npm run test:reveal` 13/13; `docs/hit-areas-2026-09-01.html` carries the regions for curved, straight and elbow, and for a Block with and without ports.
- Rebuilt how a cable decides which end is its source. A port has a side and up to two faces (outer in its Block's scope, inner for an Expanded Block's inside); polarity follows from side and face, the faces follow from the two Blocks' places in the frame hierarchy, and one `judgeConnection` decides every drop, highlight, picker landing and load-time validation. Nothing is decided at the press any more — the press rule that started every cable from an Expanded Block's inner face is what made siblings unwireable, picker spawns output-to-output, and cables leave outputs the wrong way. Bindings now carry `face` (old `x__inner` ids migrate), settled cables are normalised so `start` is the source, a picker-spawned Block is created in the scope the cable landed in, and an inner-face cable no longer treats its own frame as an elbow obstacle.
- Inputs fan in. A second cable onto an occupied input joins it instead of replacing what was there; a press on any dot starts a new cable, an existing cable is re-routed by selecting it and dragging its terminal handle (a press on a tldraw overlay is now left to tldraw before a dot may claim it), and the only drop a sink refuses is an exact duplicate of a wire it already has.
- Gave SystemSketch its own document type. A `.systemsketch` is a tldraw file — same `tldrawFileFormatVersion`, `schema` and `records` — with one extra top-level `systemSketch` key in front of them holding a plain inventory of what the board contains. Everything the app creates is now a `.systemsketch`; a `.tldr` still opens, edits, and saves back as a `.tldr`, unconverted, and an existing `Untitled.tldr` stays the document a clean launch opens. The suffix decides the encoding in both directions, enforced independently by the browser and the Python host, and rename can no longer change a document's type. Because tldraw's file validator rejects unknown top-level keys, tldraw.com declines a `.systemsketch` early rather than half-loading a board it has no Block or cable utils for.
- Stopped a browser journey from opening a real GTK file chooser on the developer's desktop: an installed `zenity` is not a desktop session, so a controller with no `DISPLAY` or `WAYLAND_DISPLAY` now reports the native chooser unavailable and the in-app browser takes over, and the shared test harness starts its API child with no display at all.

- Brought file browsing inside the app, and gave every board its own window. Open used to hand the modal to `zenity`: the Python host ran it as a subprocess **inside the HTTP handler, with no timeout**, and the browser awaited that fetch with no deadline either — so a wedged GTK chooser wedged File › Open with it, and the in-app dialog the code already carried as a fallback could only ever fire on a *fast* failure. That reverses the earlier "native chooser, in-app browser as fallback" decision — and supersedes the `DISPLAY`/`WAYLAND_DISPLAY` guard added a commit earlier, which kept the chooser off a headless controller's desktop but left a desktop session pointed at the same wedge: the second process is gone entirely, and the app's own browser is the chooser. It grew what a chooser you actually use needs — the filter box holds focus so `Ctrl+O` → type → `Enter` is the whole gesture, a filter that hides the selected row moves the selection to the first row still visible, arrow keys and `Backspace` walk the list and the folders, and a breadcrumb replaces the truncated path. A Python test now greps `scripts/` for `zenity`, `kdialog`, `yad` and `--file-selection`, so re-adding an out-of-process chooser turns `npm run check` red. **Windows**: `Ctrl+Shift+N` (File › New window) opens a second real desktop window on a fresh board and **Open in new window** sends the selected one to its own; each window titles itself after its board so a taskbar full of them reads. The popup handle is taken synchronously inside the gesture and pointed at the board afterwards, because Chrome blocks a popup opened after an awaited round trip — and two windows can no longer both claim `Untitled 2`, since each records a short-lived local reservation that expires. Proven in the real product: `npm run test:workspace` 10/10 in headless Chrome, and `npm run test:windows` 4/4 in a genuine Chrome `--app` window on a private Xvfb display, where the window count and per-window titles are read from the X server rather than the DOM.
- Added the literal-argument pill: the Block's fourth view, `value`, a capsule as wide as its text with an inlet on its left rim and an outlet on its right — a variable, so a source, a sink or both depending on what is wired; a fed pill shows `⋯` and keeps its literal for when it is unwired. **P** draws one (the stock box tool; the shape util's create seam turns the blank Block into a capsule on the click path tldraw never reports to a tool), a cable dropped on nothing can pick **Value**, the literal is the title, the ports' name is the variable name (empty means passed inline), the type is inferred from the literal or read from the feeding cable, the inspector shows a Pill section (Name, Value, Type, wiring) in place of the Block sections, a literal past 18 characters folds to `= …` with the full text in the tooltip, and a wired input dims its definition-default chip so a supplied literal and a default never share a rendering. Older files load through migration 3; `npm run test:pill` proves it in Block Dev and the product.
- Added **Detach to primitives** and its inverse. A Block becomes ordinary tldraw geo, text, line and arrow shapes — the full stock style panel, no dependency on SystemSketch — arriving as ONE group whose `meta` carries the entire Block record: title, type, notes, icon, every port with its durable id, the remembered per-view boxes. Cables become stock arrows that remember their ports. **Rebuild Block from primitives** reads it back, at wherever the group was left rather than where the Block once was, and re-forms the semantic cable — against a Block that was rebuilt or one that never left. `meta` survives save, load, copy and paste untouched and stock tldraw ignores it, so the same `.tldr` is rectangles-and-text on tldraw.com and Blocks in SystemSketch. One Ctrl+Z undoes a whole detach. Ported from pyblocks' `src/pipeline/nodes/detachNode.ts`; the record is the new half.
