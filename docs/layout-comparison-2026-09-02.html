Tidy edges = preserve the board

Moves only shared interior rails. Endpoints stay welded; nodes stay put; authored elbow routes are immovable constraints; curved and straight edges are ignored. The 14-unit pass is deterministic and undoable.

Organize nodes = choose new positions

Moves Blocks through a one-shot, selection-first ELK layout. It preserves reading/model order when free, anchors the result where the input began, and takes no edge geometry from ELK—the stock SystemSketch elbow router redraws it.

What was actually evaluated

Edge path: each fixture feeds the shipped pure nudgeRoutes implementation. The report validates orthogonality, fixed endpoints, forced-crossing classification, immutable authored routes, and before/after coincident-run length.

Node path: each fixture feeds the shipped organizeGraph wrapper and the exact PyBlocks/Dify-derived ELK option block. The output is run twice byte-for-byte to assert determinism, then every cable shown is recomputed with SystemSketch’s own routeElbow.

Prior decision trail:

  • Edge-overlap research — fixed-node routing vs. layout engines.
  • Left-to-right feedback research — one-shot interaction precedents.
  • PyBlocks implementation report — original Nudge/Tidy port source.

Pink CONSTRAINED cases retain geometry the contract says not to move. Amber TOPOLOGY cases contain a crossing no one-dimensional channel order can remove. Those are surfaced, not hidden.
