SystemSketch prior-art scan

What people add after stock tldraw

A source-verified scan of open-source applications that keep tldraw as the canvas engine and add durable objects, domain semantics, agent control, or collaboration context. Ranked for ideas transferable to SystemSketch—not by GitHub popularity.

Researched 31 August 2026 · GitHub repositories and official tldraw documentation
⚖
“Open-source app” does not make the current tldraw SDK open source. Since SDK 4.0, tldraw itself is source-available under the tldraw license and needs a production key. The projects below have an OSI-style app license; their tldraw dependency retains its own terms. Projects with public code but restrictive or missing licenses were excluded from the main list.

The actual pattern

Almost nobody wins by adding ten more primitive drawing tools. The best projects change what lives on the canvas and how it connects to the rest of the work.
01

Semantic shapes

Domain objects, structured panels, documents, terminals, or media nodes—not prettier rectangles.

02

Durable truth

Files, ledgers, rooms, and markdown remain canonical while the canvas is an editable projection.

03

Canvas APIs

Agents and external tools can read and mutate the same spatial state humans are viewing.

04

Contextual chrome

The controls follow the job: workshop playback, one-keystroke sharing, teaching, or live development.

Ranked shortlist

Filter by the type of extension you want to study. “Active” reflects repository activity at research time; it is not a quality guarantee.
1

DDD Toolbox

ActiveAGPL-3.0tldraw 4.0.3

Purpose-built Domain Storytelling, Event Storming, and Bounded Context canvases. Adds custom actors, work objects, comments, activity arrows, domain panels, guided placement, numbering, grouping, document persistence, and a story “play” mode.

Borrow: one semantic model can drive a very different tool grammar while still using tldraw’s selection, camera, bindings, and history.

2

biliboss/canvas

Active / tinyMITtldraw 5.3.2

Places a project’s Markdown documents, a task ledger, Mermaid diagrams, and structured Toyota A3 sheets on one canvas. Files remain canonical; SSE refreshes shapes when disk changes; dragging a task card writes a domain event. An HTTP API lets headless agents focus or alter the live board.

Borrow: this is the closest architectural rhyme with SystemSketch: filesystem truth, semantic projections, child shapes, and an agent-readable canvas.

Repository ↗
3

EnsembleWorks

Very active / earlyAGPL-3.0tldraw 5.1.0

A multiplayer team room with live tmux terminals, embedded dev servers and browsers, screen-share shapes, spatial voice/video, transcripts, session layouts, and a CLI/API through which agents read frames and post real bound shapes.

Borrow: shapes can be live working surfaces, not thumbnails. Its explicit separation between tldraw spatial state and content channels is particularly strong.

Repository ↗
4

Cutting Board

Small / focusedMITtldraw 3.15.3

A macOS menu-bar whiteboard that appears via global hotkey, accepts pasted screenshots, persists between invocations, and copies the whole board to the clipboard as a PNG. A local MCP server can inspect and edit the live board.

Borrow: it improves the whiteboard through invocation and exit—the path from thought to shareable artifact—rather than canvas mechanics alone.

Repository ↗
5

OpenCanvas

EarlyMITtldraw 3.x

A local-first, BYO-model canvas where an LLM creates typed widgets: Markdown, charts, Mermaid, Kanban, code, and sandboxed custom HTML. Includes MCP and REST control plus reusable widget templates.

Borrow: a small typed-widget protocol is a better agent boundary than asking a model to push arbitrary raw tldraw records.

Repository ↗
6

BigBlueButton

Mature / activeLGPL-3.0Maintained tldraw fork

Integrates a tldraw-derived whiteboard into a full virtual classroom: presentation slides, presenter/viewer roles, multi-user controls, recordings and playback, realtime annotations, and conferencing lifecycle. It maintains a bundled fork for its embedding and cross-window needs.

Borrow: the deepest public reference for fitting a canvas into a mature host application with roles, document pages, recordings, and long-lived compatibility constraints.

Repository ↗
7

Tolaria

ActiveAGPL-3.0tldraw 4.5.x

A desktop Markdown knowledge-base app with durable fenced tldraw blocks. Each block stores a stable board ID and document snapshot inside Markdown, updates through the normal autosave pipeline, follows light/dark mode, and can expand into a full-window workspace without changing its stored identity.

Borrow: the embedded/fullscreen duality and durable codec are a clean model for treating a sketch as one rich block inside a larger document system.

Repository ↗
8

Open AI Canvas

ActiveMITtldraw 5.2.5

An AI film and short-video workbench with canvas projects, multimodal generation, structured storyboards, character/style assets, task queues, read-only sharing, cross-device persistence, a Canvas Agent, MCP tools, and a Codex app plugin.

Borrow: selection and upstream-node context become an explicit input bundle for an agent, with results inserted back into the spatial workflow.

Repository ↗
9

Thought Partners

Prototype / inactiveMITtldraw 3.11

Combines a shared room-based whiteboard with LiveKit video. Speech-to-text becomes collaborative notes grouped by participant and minute directly on the canvas; a floating call panel keeps conversation and artifact in one surface.

Borrow: spoken collaboration can leave spatial, attributed residue instead of producing a separate transcript nobody revisits.

Repository ↗
10

Revezone

Inactive since 2024AGPL-3.0old tldraw canary

A local-first desktop “second brain” combining tldraw and Excalidraw boards with Notion-like notes, folder management, browser/local storage modes, and draggable split-screen layouts.

Borrow: the valuable part is workspace composition—boards beside notes and file navigation. Caveat: the repository states that it contains only basic functionality and does not match the full hosted/desktop product.

Recommended reading order for SystemSketch

Study three seams, not ten products.

DDD Toolbox shows how to replace the generic whiteboard vocabulary. biliboss/canvas shows how disk truth and semantic canvas objects can round-trip. EnsembleWorks shows how live content and agents coexist with tldraw state without stuffing every byte into shape props.

For interaction polish, keep Excalidraw as the visible oracle. The public tldraw projects are much stronger evidence for semantic architecture, persistence, and host integration than for improving primitive drawing feel.

1DDD Toolbox: custom ShapeUtils, tools, placement preview, story playback.
2biliboss/canvas: file watcher → shape projection → drag writes domain fact.
3EnsembleWorks: live shape content, spatial collaboration, canvas read/write API.
4Official starter kits: current SDK patterns for agent, workflow, chat, and multiplayer.
