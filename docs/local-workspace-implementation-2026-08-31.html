The happy path

1Launch

Reopen the most recent valid document; otherwise prepare ~/SystemSketch/Untitled.tldr.

2Draw

User document edits queue tldraw's own serializer. No parallel SystemSketch file schema exists.

3Autosave

A 600 ms debounce writes pretty JSON through an atomic temporary-file replace.

4Reopen

Recents and the URL binding restore the same file; desktop double-clicks open .tldr directly.

Safety that stays out of the way

Allowed root

The controller rejects traversal and symlink escapes beyond the configured local root.

Atomic writes

Validated JSON is fsynced to a sibling temporary file, then replaced in one filesystem operation.

External watcher

Clean boards reload silently. Dirty boards pause and ask before either revision can win.

Digest fence

Every write compares exact content identity, catching races that timestamp polling cannot see.
