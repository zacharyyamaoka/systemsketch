SystemSketch · Block, Ports & Edges · 1 Sep 2026

Whatever you type is already saved.

Renaming a port in the inspector and clicking onto the canvas dropped the edit. The panel's fields wrote the document on blur — and clicking the canvas deselects the Block, which unmounts the panel, and Chrome fires no blur for a focused element that is removed from the DOM. Every text box in the app now writes as you type, and every way out of a field is the same boundary.

9/9 real-browser checks · 108 unit tests · 24 Python tests · zero console errors

Why it happened

Not a missing handler — a missing event. The old field kept the text in React state and pushed it into the document on blur, so its correctness depended on the browser reporting an exit it does not report.

The two loss-free policies — and which one is the default

What editors actually do: the local document is the source of truth and takes the keystroke immediately; the expensive parts — undo granularity, and any network or process boundary — are handled by coalescing rather than by delaying the write. Both policies below are loss-free, because unmount is an end boundary in both.

PolicyWhat it doesCostUse it for
live
default		 Every keystroke writes straight into the shape. The document is the only copy of the text, so there is nothing left to lose. One in-memory store write per character. Already what the on-canvas editor does. Everything in the inspector today.
exit Buffered, written once at the end boundary — including unmount, which is why it is still loss-free. The canvas lags the field until you leave it. Not WYSIWYG while typing. A field whose write is genuinely expensive.

For the Python backend: don't couple the rename RPC to the keystroke. The document write and the backend event are different boundaries, and the field model already separates them — onWrite fires per keystroke, onEditEnd fires exactly once per editing gesture with both the old and the new value. So a semantic rename(port_id, from, to) hangs off onEditEnd and the canvas never waits for the round trip. If you later want live streaming instead, subscribe to the store — no field code changes.

A second bug the proof turned up

Writing per keystroke is only safe if the keystrokes are bounded in history. While checking that, the baseline probe showed the on-canvas editor — which already wrote live — had never bounded its own typing: undoing a rename merged into the Block's creation and deleted the Block. Both editors now stamp one history mark per editing session, lazily, on the first character that actually changes something.

This is a requirement you already wrote down

Two FRs from the Workbench work say exactly this, and the behaviour here now matches both: one gesture is one undo step — the snapshot at gesture start, the commit at gesture end, so a rename is one Ctrl+Z; and text keeps its native character-level undo — while the caret is in a field, Ctrl+Z belongs to the field and must not reach past it and rip something off the canvas. tldraw already skips its own shortcuts when the event target is an input, and the ninth browser check now proves the Block behind the panel survives an undo pressed mid-edit. That FR recorded an honest coverage gap — “inspector fields … not yet probed by a test”. In this app they are.

Two calls I made, both easy to reverse

Escape exits, it does not discard

tldraw's own Escape is a global cancel that deselects the shape and unmounts the panel before a field can react — and its on-canvas text editor keeps what you typed on Escape. Rather than fight that, Escape here means “leave the field”, and Ctrl+Z is the retract — one press for the whole rename. Say the word if you want Escape to revert instead; it needs the field to claim the key via editor.markEventAsHandled.

The workspace dialogs were left alone

Open / Save a copy / Rename keep their own text state and commit on the Save button. That is a modal transaction with an explicit Cancel, not a field that silently vanishes, so it is not the same defect. Everything else that takes typing now goes through the field contract.
