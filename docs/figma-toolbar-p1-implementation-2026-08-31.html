Documented escape hatch

P1 now. P2 only if the shell fights us.

The upgrade is deliberately bounded. Product behavior is not coupled to the toolbar container, so future pressure does not require rewriting family memory, tools, shortcuts, the library, or tests.

Keep P1 while it stays boring

DefaultToolbar gives SystemSketch the maximum off-the-shelf tldraw behavior and the smallest maintenance surface. This is the shipped choice.

Upgrade to P2 when there is evidence

If stock overflow DOM, breakpoints, or extra toolbar chrome materially constrain the product, replace only the outer shell with an owned TldrawUiToolbar. Keep the model, overrides, curve side effect, library catalog, and regression tests unchanged.
