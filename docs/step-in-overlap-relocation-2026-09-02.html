The active scope gives way.

Stretching an Expanded Block inside Step In can no longer bury nodes that are hidden from that isolated view. On resize release, the active Block subtree moves to the nearest collision-free position; the surrounding graph remains exactly where it was.

Resize contract
stock resize→detect sibling overlap→return x / y

The search evaluates exact clearance edges and chooses the smallest page-space translation. It is deterministic and leaves a 32 px visual gap.

Depth action
Step in ↔ Step out

At Board depth, the active command says Step in. Once that same Block is the current scope, every Block command surface says Step out and returns to the parent depth.

The supported post-resize seam

 101  export function steppedInResizeRelocation(
 102  	editor: Editor,
 103  	current: BlockShape,
 104  ): Pick<BlockShape, 'x' | 'y'> | null {
 105  	if (getActiveDepthScopeId(editor) !== current.id || current.props.view !== 'expanded') return null
 106  	const subject = editor.getShapePageBounds(current)
 107  	if (!subject) return null

 109  	const obstacles = editor.getSortedChildIdsForParent(current.parentId)
 110  		.filter((id) => id !== current.id)
 111  		.map((id) => editor.getShape(id))
 112  		.filter((shape): shape is TLShape => Boolean(shape && isOcclusionObstacle(shape)))
 113  		.map((shape) => editor.getShapePageBounds(shape))
 114  		.filter((bounds): bounds is NonNullable<typeof bounds> => Boolean(bounds))
 115  	const target = nearestClearTopLeft(subject, obstacles)
 116  	const dx = target.x - subject.minX
 117  	const dy = target.y - subject.minY
 118  	if (Math.abs(dx) < 0.01 && Math.abs(dy) < 0.01) return null

 120  	const pageOrigin = editor.getShapePageTransform(current).applyToPoint({ x: 0, y: 0 })
 121  	const parentPoint = editor.getPointInParentSpace(current, {
 122  		x: pageOrigin.x + dx,
 123  		y: pageOrigin.y + dy,
 124  	})
 125  	return {
 126  		x: Math.round(parentPoint.x * 100) / 100,
 127  		y: Math.round(parentPoint.y * 100) / 100,
 128  	}
 129  }
