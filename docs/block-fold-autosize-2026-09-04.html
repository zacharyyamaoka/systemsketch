Membership needs an explicit exit, not a brittle drag race.
Right-click an object inside an auto-fit Block and choose Remove from container. The command reparents it to the Block’s parent while preserving its page position; the source Block then refits. This is deliberately clearer than trying to infer an “outside” drag while the boundary is moving beneath the pointer.

Three stock-friendly seams

Fold the current face

The leftmost chevron is visible only on foldable Port and Expanded faces. Folding parks the full dimensions for that view, shows the compact header, and hides descendants from the active frame scope.

Fit the real children

Expanded Blocks call tldraw’s stock fitFrameToContent after document mutations. Empty Blocks keep their manually chosen starting size.

Leave without a fight

The context command uses stock reparentShapes, preserving the object’s canvas position. It appears only where an enabled auto-fit container actually owns the selected object.

Observed canvas states

Why not use a separate custom drag model? The feature keeps tldraw’s stock frame membership and uses the narrow hooks around it. The one novel behavior is a named escape hatch.

tldraw already exposes frame fitting and reparenting primitives. SystemSketch uses those supported mechanisms rather than forking frame drag, resize, or membership behavior; the 56px fit padding simply reserves room for its existing Block header.
