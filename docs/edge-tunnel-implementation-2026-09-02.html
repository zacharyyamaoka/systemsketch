Long cables can go underground.

The PyBlocks edge-tunnel behavior is now native to SystemSketch: one semantic connection remains intact while its idle middle run disappears, leaving short endpoint stubs and outlined vias. Context brings the route back without rewriting it.

Same edge, four useful views

Tunnel is presentation state, not a second line primitive. Hovering the invisible middle, selecting an endpoint or the edge, reattaching a terminal, or focusing its named layer restores the complete existing route.

Short cables remain legible

A route at or below 84 units stays complete. Above it, both 34-unit stubs and a real hidden middle fit without collapsing into an accidental gap.

Delayed edges keep their meaning

The z⁻¹ pill is hidden only while the run is underground. Any reveal context restores the route, delay dots, and pill together.
