What caused the stack overflow?

The old getGeometry implementation read live SelectTool state and descendant cached geometry while tldraw was computing the parent’s own cached geometry. That made the reactive parents depend back on themselves. Geometry is record-only again; continuous feedback is a paint-only projection, and fitFrameToContent remains the correct one-shot release operation.
