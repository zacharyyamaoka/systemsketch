SystemSketch · stock portability audit · 3 September 2026

“Stock only” is not “only four font sizes.”

For detach, stock only means the saved result contains ordinary tldraw records—arrow, geo, group, line, and text—with documented stock properties. No SystemSketch shape utility, binding, component, or custom paint layer is needed to open and render it. It does not forbid stock text scale, rich text, curved arrows, or a stock Line with as many persisted polyline points as the route needs.

Verified in a bare stock viewer, not inferred from a screenshot. The 50-case stress proof serializes the detached board to .tldr, then opens it in a route that imports only default createTLSchema and bare <Tldraw />. It renders 113 stock Lines—including ten authored multi-elbows—with no custom shapes or error boundary. The smaller primitive test also asserts a 36px heading, 18px Branch title, 11px active label, and curved Arrow.

What the pinned stock model can do

SUPPORTED

Exact effective text sizes

Text has the stock size presets s/m/l/xl, and every text record also has non-zero numeric scale. We now emit l × 1 for Block headings (36px), s × 13/18 for Branch controls, s × 12.5/18 for Loop labels, and s × 11/18 for active/turn labels.

SUPPORTED

Curves, one-elbows, and authored multi-elbows

Stock arrow has kind: 'arc' with numeric bend, and kind: 'elbow'. For a route with several authored bends, detach emits a stock line with every route point persisted in its points record. The bare stock viewer renders that complete polyline; it is not a SystemSketch fallback.

SUPPORTED

Bold signal and basic typography

Stock rich text supports marks, including bold. Detached active arm names, active, and Loop turn labels carry that ordinary rich-text mark. The stock font choices include draw, sans, serif, and mono.

SUPPORTED

Port and target geometry

Stock geo: 'ellipse' represents the 18px port rim, a 12px wired core, and the active target’s 11px blue disk plus 3.6px raised-surface disk. Branch and Loop lower to a stock Group plus a stock rectangle, so every header-edge dot is an ordinary grouped child—there is no Frame clipping wall.

Real limits of a plain stock file

Authored featureWhy it cannot be literal in bare stock tldrawDetach treatment
Exact Inter / JetBrains Mono face, CSS 500/600, tracking and line-heightA bare stock text record chooses a named stock font family and rich-text marks; it has no per-record arbitrary CSS family, numeric weight, letter-spacing, or line-height property.Use stock sans/mono, actual effective font sizes, and bold where it carries meaning. The remaining glyph/spacing residual is visible in the heat maps rather than hidden behind custom paint.
Arbitrary hex port coloursStock color is a palette style, not a per-shape CSS hex. The authored #c08520 “any” port has no identical default stock palette value.Nearest named stock palette colour; preserve geometry and connection state exactly.
Frame clipping around a header portA stock Frame clips its direct children; a live Region port deliberately straddles its wall.Do not use a Frame. Branch and Loop become a movable stock Group containing the card, label, rule, and port geos, so the full 18px rings render in bare stock tldraw.
One dynamically reroutable Arrow with arbitrary manual bendsA stock Arrow persists endpoints plus one elbow midpoint or an arc bend. It does not persist an arbitrary sequence of user-authored elbow waypoints as a single binding-aware Arrow.For exact current rendering, preserve the complete route in a stock Line. An invisible stock Arrow retains endpoint bindings for rebuild. Moving endpoint shapes later will not reroute the frozen Line like the semantic SystemSketch connection; that is the explicit editability trade-off.
SystemSketch port identity and temporal semanticsStock shapes have no SystemSketch port id, temporal type, or custom router policy.Preserve stock geometry and dash convention. Optional ignored metadata exists only for SystemSketch’s rebuild path; bare tldraw ignores it and still renders the drawing.
Custom rounded card, shadow, and background blendStock geo has its own shapes, palette, fills, and stroke-size vocabulary rather than arbitrary CSS radius/shadow/filter values.Use stock rectangle/oval/ellipse/line primitives. The composite heat maps disclose the residual.
