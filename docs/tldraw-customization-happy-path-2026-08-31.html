SystemSketch · decision roadmap · 31 Aug 2026

Keep the canvas mature. Make its objects meaningful.

The supported tldraw path is not to rebuild a whiteboard. It is to preserve its interaction engine while adding one narrow, typed seam for SystemSketch's Block, ports, persistence, and later agent control.

tldraw owns canvas mechanics

Selection, transforms, camera, clipboard, history, generic shapes, tools framework, store, and sync transport.

→
SystemSketch owns domain meaning

Block schema, port identity, view modes, commands, projection, migrations, detach, and agent contracts.

The ten-rung happy path

Each rung earns the next. Programmatic behavior comes before custom gestures; document stability comes before agents or multiplayer.

1Keep full TldrawRetain upstream UI and interaction behavior.
2Type one BlockValidated props, stable port IDs, migrations.
3Bridge with ShapeUtilOne concrete util and one pure layout authority.
4Create by commandProve Editor CRUD before pointer logic.
5Unify editingCanvas and inspector dispatch the same typed command.
6Bind semanticsSeparate spatial attachment from port meaning.
7Reload and migrateProve durable documents before widening scope.
8Add placement toolOnly after command-driven creation is solid.
9Adjust chromeReplace the smallest slot that removes friction.
10Expose API / syncTyped domain operations first; collaboration later.
Sequencing principle: shape data → shape behavior → domain command → persistence → gesture → chrome → external systems.

What each reference proves

Open a card for the transferable lesson. The detailed source scan remains the evidence ledger.

DDD Toolbox · domain grammar

Semantic shapes, tools, panels, guided placement, and story playback can transform the job while retaining tldraw's generic canvas mechanics.

biliboss/canvas · canonical files

Files can remain truth while shapes are reactive projections and gestures emit explicit domain events.

EnsembleWorks · live surfaces

Spatial records and live content channels deserve separate lifecycles; shapes may host working surfaces rather than static previews.

Cutting Board · invocation and sharing

A one-keystroke capture-to-export loop can improve the overall whiteboard more than deeper canvas machinery.

OpenCanvas · typed widgets

A small typed widget/command language is a safer agent boundary than arbitrary internal record mutation.

BigBlueButton · integration cost

Roles, presentations, recordings, and host lifecycle reveal when deep embedding may eventually justify long-lived compatibility ownership.

Tolaria · durable identity

Stable IDs and a real document codec let one board move between embedded and fullscreen contexts without becoming a new artifact.

Open AI Canvas · agent context

Selection and upstream relationships should be explicit inputs, with results returning as editable objects in the same workspace.

Thought Partners · spatial residue

Ephemeral collaboration becomes useful when it leaves attributed, organized artifacts on the shared surface.

Revezone · workspace composition

Boards beside notes and files are attractive, but the surrounding workspace can outrun the core artifact if added too early.

The ownership boundary

A good happy path makes good behavior cheap by keeping each responsibility on the side already designed to carry it.

Keep upstream

  • Selection and transforms
  • Camera and coordinate systems
  • Clipboard and history
  • Generic shapes and arrows
  • Shape/edit lifecycles
  • Store reactivity and schema hooks
  • Tool framework and sync transport

Own in SystemSketch

  • Block schema and stable port identity
  • View modes and layout authority
  • Typed domain commands
  • Semantic relationship meaning
  • Canonical-file projection
  • Migrations and detach recipe
  • Agent and external API contract
First product gate

Three Blocks. Two links. Reload. Edit. Undo. Reopen.

If that journey is native, durable, and unsurprising, SystemSketch has earned the next mutation. If a proposed feature does not help this journey, defer it or prototype it separately.
