Reference quality first

What the mature projects actually do

The supplied branch is included prominently, but its absences matter as much as its ideas. draw.io is the closest mature local-file comparison.

Strongest direct analogue

draw.io Desktop 31.4.2

A mature desktop whiteboard with a real local-file watcher, save conflicts, backups, synchronous writes, read-back verification, bounded higher-level saves, and explicit Copy / Merge / Overwrite / Cancel recovery choices.

Do not overclaimIts primary save still truncates in place, checks mtime rather than a content revision, and has no cross-process lock. SystemSketch's transaction is narrower but stronger because Stable and Preview are separate writers.
save precondition + fsync + read-back retry ↗watcher + semantic checksum ↗save while edits continue ↗bounded sync + late-result rejection ↗named conflict recovery ↗maintainer discussion: synced-folder corruption ↗
Best persistence-loop precedent

tldraw (current local sync)

Its IndexedDB client keeps writes single-flight, lets new diffs accumulate while a persist is running, and turns a failed incremental write into a later full snapshot.

Do not overclaimThis is browser-local IndexedDB, not an OS-file protocol. It validates the queue and retry shape, but it cannot supply the path lock or disk conflict contract.
single-flight queue + full-write recovery ↗the exact Radix modal used by tldraw 5.3.2 ↗
Useful desktop prior art, not the gold standard

tldraw-offline · pre-internal

The supplied 17-commit branch centralizes renderer diffs, writes per-document recovery JSON every second with temp-then-rename, bounds renderer serialization at 30 seconds, and gives concrete choices after external deletion.

Do not overclaimCanonical .tldr saves are direct writeFile calls, dirty state is cleared before the write, failed recovery writes are not requeued, and same-path content edits are ignored. It has no digest, CAS, lock, bounded file read, or portable export path.
exact supplied snapshot ↗per-document recovery + atomic helper ↗30-second renderer request budget ↗direct canonical-file write ↗
Deliberately thin local-file comparison

Excalidraw

Its direct disk path delegates to browser-fs-access. The stronger concurrency ideas live in collaboration: clone before an async save, transact against current remote state, and protect elements being actively edited during reconciliation.

Do not overclaimThe local path has no mtime/digest watcher, lock, or no-clobber layer; a local attachment failure explicitly does not retry. This is evidence to keep SystemSketch's policy small, not evidence that a desktop multi-writer file protocol is unnecessary.
thin local-file adapter ↗clone before async collaborative save ↗transactional reconcile-before-write ↗active-edit reconciliation fence ↗

Accepted scope · code-adjacent reasons

Eight changes, eight concrete “why” comments

Checkboxes start from your review. You can revise any one and copy a compact Markdown reply; notes stay in this browser only.

Static file; no report server required.
01
Keep — concrete SystemSketch race

Cross-process revision transaction

Why it exists here

Stable and Preview are independent threaded server processes. Without one OS lock around check + replace, two windows can validate the same digest and silently last-write-wins.

What the references actually support

draw.io checks the prior mtime and rejects overlapping saves; Excalidraw uses a true transaction for concurrent cloud writers. Neither provides the local multi-process primitive.

scripts/workspace_store.py · document_locks / save_documentWHY: Stable and Preview are independent processes; a threading.Lock cannot make digest-check + replace one transaction.
Executable evidencePython contention tests: exactly one same-base winner; save/rename/trash remain serializable.
02
Keep — product invariant

Non-destructive, no-clobber portable export

Why it exists here

Export previously mutated the live editor and forced destination replacement. The existing portable clone now owns conversion; a target changes only after an explicit Replace choice.

What the references actually support

tldraw-offline delegates image export to stock tldraw; Excalidraw keeps export single-flight. The exact clone/no-clobber guarantee is SystemSketch-specific and is retained because it is tested.

src/workspace/LocalWorkspace.tsx + src/export/portableTldraw.tsWHY: export must not mutate the live board, undo history, dirty state, autosave, collaboration, or host bridge.
Executable evidenceBrowser export journey compares live snapshot/source bytes and requires Replace for an occupied target.
03
Keep — smallest local equivalent

Edit-fenced automatic reload

Why it exists here

The stat → read sequence yields twice. A canvas edit or completed save arriving between those requests must invalidate the old result before it can replace editor state.

What the references actually support

draw.io preserves edits made while Save is pending and rejects late sync results; Excalidraw protects actively edited elements during remote reconciliation.

src/workspace/LocalWorkspace.tsx + workspaceModel.ts · canApplyExternalReloadWHY: capture both local identities before awaiting disk so a slow read cannot overwrite an intervening edit or save.
Executable evidencePredicate regressions reject changed edit epoch, base digest, or loaded disk digest.
04
Keep — stronger, narrowly scoped identity

Exact-byte digest identity

Why it exists here

mtime and size can both collide after a rapid same-length rewrite. SHA-256 is used only as revision identity; reads are raw, bounded, and decoded after hashing.

What the references actually support

draw.io combines mtime with a semantic page checksum; Excalidraw combines per-element version and nonce. SystemSketch uses a raw digest because its unit of concurrency is one disk file.

scripts/workspace_store.py · _read_identity; src/workspace/workspaceModel.ts · sameFingerprintWHY: a rapid same-length rewrite can preserve both mtime and byte count; the exact-byte digest is authoritative.
Executable evidenceSame-size/same-mtime and CRLF/LF regressions prove changed bytes produce a changed revision.
05
Keep — mature direct precedent

Bounded requests + single-flight polling

Why it exists here

A loopback process can hang or restart. Requests need operation-specific budgets, while a 1.5-second interval must not stack behind a slow stat/read.

What the references actually support

tldraw-offline bounds renderer serialization at 30 seconds. draw.io rejects concurrent saves and bounds its higher-level synchronization even though raw IPC is unbounded.

src/workspace/workspaceClient.ts · requestPayload; LocalWorkspace.tsx · watch effectWHY: even loopback calls can stall; combine caller cancellation with deadlines, and never stack stat polls.
Executable evidenceControlled fetch tests classify timeouts/aborts; browser journey finishes without transport or console errors.
06
Keep — constrained retry, not a framework

Bounded transient autosave retry

Why it exists here

A failed save may follow the person's last edit. If retry waits for another edit, the board can remain dirty forever. Only transient transport/server failures retry; conflicts never do.

What the references actually support

Current tldraw schedules a full snapshot after failed incremental persistence. draw.io retries failed read-back verification and exposes retry for other failures. Excalidraw local attachments do not.

src/workspace/LocalWorkspace.tsx · persist; workspaceModel.ts · autosaveRetryDelayWHY: transient failure must resume saving without another edit; semantic failures and revision conflicts wait for a person.
Executable evidence1s / 3s / 8s policy tests; retry classification excludes conflicts, validation errors, and forced writes.
07
Keep — clearest mature precedent

Visible, named recovery actions

Why it exists here

Discarded File-menu promises made failures invisible; bootstrap errors stranded the app. Persistent document alerts now name the next safe action, while short action failures become visible notices.

What the references actually support

draw.io offers Make Copy / Merge / Overwrite / Cancel and explicit backup recovery. Excalidraw surfaces local-quota and collaboration failures instead of silently continuing.

src/workspace/LocalWorkspace.tsx · runAction / WorkspaceLoading / WorkspaceAlertWHY: states that can lose work stay visible beside named recovery actions instead of disappearing like a toast.
Executable evidenceAll launched actions have a rejection boundary; initial load exposes a real Try again route.
08
Keep behavior; replace custom machinery

Real keyboard modal

Why it exists here

The file browser still needs modal focus, Escape, outside dismissal, and focus restoration—but SystemSketch does not need to implement those primitives itself.

What the references actually support

tldraw 5.3.2 implements its own dialogs with Radix Dialog. SystemSketch now imports the same already-pinned dependency and retains only its app-specific browser content.

src/workspace/LocalWorkspace.tsx · WorkspaceDialogWHY: Radix is already SystemSketch's dialog dependency and the primitive tldraw uses; let it own modal semantics.
Executable evidenceThe unchanged 11-check browser journey proves initial focus, both Tab-loop ends, Escape, return focus, and zero errors.

Rule carried forward

Comments explain the product failure, not “best practice.”

Use stock tldraw or an installed primitive when it owns the behavior. Use small browser/POSIX mechanisms only where SystemSketch's local-file boundary has a failure those primitives cannot represent. Keep tests as executable evidence; do not grow a second filesystem framework.
