A behavior-tree arrow that knows where to bend.

Slanted is an uncommon ordinary-arrow route: it leaves a bound source on that face’s normal axis, then reaches its destination in one diagonal. Loose arrows use the dominant endpoint axis. It lives only in the Inspector, keeps the everyday arrow menu small, and stays a valid stock tldraw arrow when opened elsewhere. Its elbow begins at the established automatic lead and becomes an authored control only when dragged.

Decision from prior art

Use React Flow’s explicit source direction and ELK’s short-then-sloped reading, not either engine’s full layout pass. React Flow exposes sourcePosition specifically so a route can leave the correct side; ELK’s polyline sloped-edge zone preserves a readable short run before the slope. A freeform SystemSketch arrow must not let layout relocate authored endpoints, so it reads the existing binding face and reuses the established connection-lead scalar; SVG’s native orient="auto" supplies the diagonal arrowhead orientation.

What was borrowed, what was not

React Flow source positions

React Flow’s SmoothStep utility accepts explicit sourcePosition and targetPosition. That is the key contract: a branch should leave the port or source face that actually owns it.

Borrowed: direction-aware departure semantics.

ELK polyline routing

ELK’s sloped-edge-zone option preserves readable polyline runs while allowing a slope where one is needed. POLYLINE is an official routing mode.

Borrowed: the short-run-then-slope visual grammar.

Why no new router

ELK’s layout algorithms own node placement; calling them for one manually drawn arrow would change the whiteboard’s contract. libavoid is a separate obstacle-router runtime, not a dependency needed for this two-segment route.

Kept: authored endpoints and stock binding behavior.

Stock fallback

The custom route is a versioned namespaced meta enhancement on an otherwise valid, zero-bend stock arrow. Switching back to Straight writes a JSON tombstone because tldraw merges nested metadata patches.

Result: no forked tldraw arrow schema and no stale custom route.

One narrow dataflow
1 · SelectAn ordinary tldraw arrow opens the facts Inspector with no new toolbar preset.
2 · Set SlantedA versioned metadata flag is added while the stock fallback becomes a zero-bend arrow.
3 · DefaultThe source binding face, or a loose arrow’s dominant axis, chooses the virtual elbow’s short lead.
4 · DragThe dot promotes to a vertex and stores only its relative position along that source axis.
5 · RevertStraight tombstones the metadata and returns the same arrow to the stock renderer.
