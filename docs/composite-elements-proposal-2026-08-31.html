Composite elements need a contract, not a kingdom of base classes.

Build the Block as one custom tldraw shape, let tldraw own its canvas lifecycle, and add a thin SystemSketch capability registry for the three product behaviors: inline fields, inspector sections, and detach plans.

Direct answertldraw has the lower-level bases—ShapeUtil, BaseBoxShapeUtil, and BaseFrameLikeShapeUtil—but no built-in “CompositeElement” that supplies inline editing, an inspector, and detach. The image-pipeline kit adds a useful NodeDefinition registry, but that is starter-kit application code, not an SDK base.

First split the overloaded word “composite”

The earlier pyblocks research already reached the important principle: the Block is renderable from primitives but not semantically reducible to them. Four different relationships were hiding under one word.

Visual composite

One atomic custom shape

Several labels, rules, dots, and panels render inside one selected canvas object. These are not permanent child records while the Block is intact.

Semantic composite

Typed content + stable identities

Title, description, ports, role, links, and view state belong to the Block model. A port ID does not change when its visible name does.

Container composite

Expanded behaves like a frame

Only Expanded needs real child shapes. Use BaseFrameLikeShapeUtil for containment, clipping, reparenting, and frame-style selection.

Shared definition

Several occurrences, one meaning

Linked copies share selected semantic content while keeping placement, view mode, and per-view sizes per occurrence. This is separate from visual composition.

Not “ungroup”

Detach transfers authority

Detaching materializes ordinary shapes, preserves the picture, and gives up Block behavior, semantic port identity, linked identity, and Inspector support.

Not a runtime mode

Edit state stays transient

Double-click editing uses tldraw’s one-editing-shape lifecycle. Position/content locks and definition/instance ownership stay separate decisions.

Load-bearing rule

layoutBlock() is the one geometric truth

The renderer, hit geometry, field editor placement, port anchors, selection indicator, SVG export, and detached primitive plan all read the same immutable layout value.

This is the practical answer to “built from primitives”: not dozens of live child records, but one deterministic visual recipe that can be materialized on demand.

Three surfaces, one command path

Pick a behavior to see where ownership changes. The inline editor and inspector differ only in gesture and presentation.

1 · Double-click fieldDOM marker or layout hit-test resolves title, description, or a stable portId.
2 · Enter tldraw edit stateThe editor still owns focus, Escape, click-away, drag suppression, and the one-editing-shape invariant.
3 · Dispatch typed commandsetCompositeField(shapeId, field, value) updates live. No second draft model.
4 · Finish semantic side effectsRename-link reconciliation or validation waits for edit end; one gesture remains one undo.
1 · Select BlockAn explicit Details action opens the optional right panel; selection alone need not force it open.
2 · Read descriptorsThe registry supplies sections, field types, labels, visibility, and capability—not the ShapeUtil.
3 · Dispatch same commandThe panel calls the same setCompositeField used by inline editing.
4 · Store drives both viewsThe canvas and inspector react to the same immutable shape record. No synchronization bridge.
1 · Preview lossesBlock behavior, linked identity, Inspector, and semantic port identity are explicitly named.
2 · Build planblockPrimitives(layoutBlock(shape)) returns stock shape partials and endpoint remaps.
3 · One transactionCreate parts, preserve children, convert/rebind cables, delete custom bindings, then remove Block.
4 · Hand authority overSelect the new primitives. They are ordinary tldraw shapes; one Undo restores the semantic Block.

Acceptance evidence

The proposal is complete only when the behaviors remain whiteboard-native under real interaction, not just when TypeScript compiles.

Editing

Exact field, exact lifecycle

Double-click the visible title, type, description, icon, port name, or port type; Enter/Escape/click-away work; the Block cannot drag or resize while editing; one gesture is one undo.

Inspector

Parity, not duplication

The same change from the inspector and canvas yields the same shape record. Nothing selected means no SystemSketch inspector. Vanilla shapes keep vanilla controls.

Detach

Faithful picture, explicit loss

Only stock records remain; bounds and anchors match; nested children survive; cables become arrows; semantic bindings vanish; one undo restores the Block.

Persistence

Migrations and reload

Old Block props migrate; current Block reloads with the same view sizes, port IDs, selection-independent content, and no session edit state serialized.

Containment

Frame contract

Drop inside/outside, move, resize, clip, erase, select-all, copy/paste, and nested detach behave like the tldraw frame contract where Expanded opts in.

Boundary

Stock remains the datum beneath

The product adds only the whitelisted Block/connection/composite seams. The Stable/Preview release boundary and ordinary whiteboard interactions remain intact.
