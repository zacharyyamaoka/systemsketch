Primitive component atlas

Every registered primitive, decomposed into the smallest components that compose it. Built from the product's own SYSTEMSKETCH_SHAPE_UTILS list and src/container/registeredComponents.ts — re-run the builder rather than trusting these numbers.

The finding. Hit-testing and port dots were extracted years ago and are genuinely shared. Painting now is too — Text slot, Chip, Disclosure, Header band route through src/container/. That did not mean re-rung every header: Branch arm (32), BehaviorTree (44), Branch (40) are deliberately still off the shared ladder rather than silently re-baselined — see their notes in the decomposition table below.

And the count was wrong. This page first said four header bands had drifted. Sweeping the source tree rather than the files the registry happened to name found six: a Branch-band at 40 that the Branch entry claimed did not exist, and a BehaviorTree-groupHeader at 48 painted as SVG in the Process projection, hand-typed to the value the Block already had. Both are now accounted for — the Branch band is routed, and the SVG band’s value reads the ladder even though its paint cannot.

The vocabulary

9 components. 4 now route through shared code under src/container/; the rest are still named but not extracted. Zach's rule for the smallest ones: a Port is a circle and a text slot, and it does not define what goes in that slot. That rule is what makes them composable.

Each card also carries its drag role — whether that component can be a dnd-kit drag source or drop target. Every painter here renders ordinary React DOM inside tldraw's HTMLContainer, so participation is free; what the role encodes is which presses are already spoken for. It is a gesture role only: PEP 0009 rules that dnd-kit owns the sensor and the handle and nothing else, and the reducer stays the oracle for what a drop does. This page is generated from src/container/registeredComponents.ts, so it cannot drift from the code — a new component or a changed composition edge shows up here the next time the builder runs, with no edit to this file.

Header bandshared

The one-row header LANE at a rung. Its tenants are Glyph, Title, Chip, Type and Disclosure — placed as children by Block, Branch and BehaviorTree, and as absolutely-positioned siblings over the band by the Loop, whose title is centred against the region rather than flowed. The band owns the height and the rung; who sits in it, and how, stays each primitive's own.
